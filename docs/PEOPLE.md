# 人物档案（data/people/*.json）

每位在条目里出现的专家一页：`/p/<slug>/`。条目里的专家名，按 `name` 或 `aliases` 匹配到人物档案；匹配不上就只显示名字、不链接。

```json
{
 "slug": "charlie-munger",
 "name": "查理·芒格",
 "aliases": [],
 "en": "Charlie Munger",
 "years": "1924 至 2023",
 "epithet": "一句话身份，26 字以内",
 "identity": ["美国投资人", "伯克希尔副董事长"],
 "story": ["第一段", "第二段", "第三段"],
 "facts": [{"label": "你可能不知道", "text": "…"}],
 "timeline": [{"year": "1924", "text": "…"}],
 "works": [{"title": "《穷查理宝典》", "year": "2005"}],
 "thinking": "他怎么想问题，一两句话"
}
```

写作守则见 `docs/STYLE.md`。额外约定：

- 只写有把握的事实。不确定的细节宁可删掉，传说类的内容要写明「据说」或「真实性存疑」。
- 在世或不确定是否在世的人，`years` 写「1957 年生」，不写终年。
- 不编造引语。需要引用时，只用有明确出处的名言。
