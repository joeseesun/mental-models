# 文案风格守则（思维模型 Wiki）

目标：读起来是中国作者写的好文章，不是翻译稿，也不是 AI 腔。参考标杆：《经济学人》中文版、晚点 LatePost、好的科普长文。

## 句子
- 短句为主，一句话一个意思。长句拆开。口语里怎么说，就怎么写。
- 主动句优先。少用「被」「进行」「予以」「对……进行……」「具有……的特点」。
- 删掉翻译腔：「作为一个……」「是……的一种」「在……的情况下」「为了……的目的」。
- 不堆「的」。连着三个「的」就重写。
- 用具体的名词和动词，不用抽象大词。禁用：赋能、抓手、闭环、底层逻辑、范式转移、维度（除非数学里）、颗粒度。
- 数字、年份、人名保持原样，不要为了顺口改动事实。

## 语气
- 第三人称，冷静，有信息量，偶尔一点幽默，不抒情，不喊口号，不说教。
- 不写「让我们」「不难发现」「值得注意的是」「总而言之」「综上所述」这类套话。
- 标题和 tagline 要有画面感、有判断，不要写成定义。例：好「别想怎么成功，先想怎么必败」；差「一种从反面思考问题的方法」。

## 格式
- 禁用破折号（— –），用逗号、句号或冒号。校验会拦截。
- 中文标点用全角，数字和英文两侧不强加空格；「1 元」这种数量词前后的空格可保留原样。
- 书名用《》，论文题目用「」。

## 事实
- 润色不得改变事实、数字、年份、人名、因果。拿不准的句子，宁可保守，不可添油加醋。
- 不确定的细节宁可删掉，不要编。
